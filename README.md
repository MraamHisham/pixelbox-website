# Pixel Box Ads - Luxury Gift Boxes E-commerce

A fully responsive, bilingual e-commerce platform for handcrafted luxury gift boxes. Built from scratch as a solo project to provide a seamless user experience for ordering custom designs.

## 🔗 Live Demo
[Visit Pixel Box Ads]((https://pixelboxads.shop/))

##  Key Features
- **Bilingual Support:** Seamless switching between Arabic (RTL) and English (LTR) with dynamic layout adjustments.
- **Modern UI/UX:** Elegant, luxurious design using Tailwind CSS.
- **Dynamic Product Filtering:** Users can filter products by category (Gift Boxes, Resin, etc.).
- **Color Variations:** Interactive color swatches that update the product image dynamically.
- **Fully Responsive:** Optimized for mobile, tablet, and desktop views.
- **Direct WhatsApp Integration:** Customers can easily inquire or order directly via WhatsApp.

##  Tech Stack
- **Frontend:** Next.js (React), TypeScript
- **Styling:** Tailwind CSS
- **Backend & Database:** Supabase (PostgreSQL, Auth, Storage)
- **Deployment:** Vercel

##  How to Run Locally
1. Clone the repository:
   `git clone https://github.com/MraamHisham/pixelbox-website.git`
2. Install dependencies:
   `npm install`
3. Create a `.env.local` file and add your Supabase credentials:
   `NEXT_PUBLIC_SUPABASE_URL=your_url`
   `NEXT_PUBLIC_SUPABASE_ANON_KEY=your_key`
4. Run the development server:
   `npm run dev`
